# Mudak-Telecom
### Бесплатный IPTV Плейлист для всех
(https://raw.githubusercontent.com/Nezerak12/Mudak-Telecom/refs/heads/main/MudakTelekomIptv.m3u)
Проект содержит ссылки из плейлистов, которые были найдены в открытых источниках. Плейлист составляю преимущественно для граждан РФ и Беларуси.

## 📺 Поддерживаемые плееры:
Все, которые умеют работать с m3u, m3u8 и raw видео потоками.
Проверено на:
- VLC (Windows 11)
- Kodi (CoreElec 21 Omega, iptv simple client)

## ⚖️ Юридическая информация

В этом репозитории не хранятся видеофайлы. Репозиторий содержит только ссылки на общедоступные URL-адреса видеопотоков, которые, насколько нам известно, были намеренно опубликованы владельцами авторских прав или доступны в открытом доступе.

Обратите внимание:
1. Мы не контролируем серверы, на которых размещены потоки.
2. Удаление ссылки из плейлиста не удаляет контент из интернета. Для удаления контента необходимо обращаться к хостинг-провайдеру источника потока.
